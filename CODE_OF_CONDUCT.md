# Code of Conduct

We are committed to a welcoming, respectful, and harassment-free project for everyone.

Participants must be respectful, use inclusive language, accept constructive feedback, and avoid personal attacks, harassment, discrimination, or unwanted contact.

Maintainers may remove comments, reject contributions, or restrict participation when conduct violates these expectations. Report concerns privately using the process in `SECURITY.md` when they involve a security or privacy issue.
